# Security

Do not include API keys, session cookies, personal travel plans, or Home Assistant
configuration in public issues. Report vulnerabilities privately through
[GitHub security advisories](https://github.com/ColeMundus/ha-tsa-wait-times/security/advisories/new).

This integration is not affiliated with or endorsed by the TSA. Wait estimates
must not be relied on as a guarantee that a traveler will make a flight.
